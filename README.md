# Orange-Telecom-Churn-Analysis-

## Description 
This project analyzes customer churn behavior for a telecom company using interactive dashboards built in Microsoft Power BI.

## Business Objectives 
- Understand the overall churn rate and its impact on revenue
- Identify key factors influencing customer churn
- Analyze the relationship between customer service interactions and churn
- Detect high-risk customer segments
- Provide data-driven recommendations to reduce churn and improve retention

##  Tools Used
- Microsoft Power BI – Data visualization and dashboard creation
- DAX (Data Analysis Expressions) – For calculated measures

## Data Analysis Process
- Data Collection
- Data Cleaning & Preparation
   - Handled missing or inconsistent values
   - Converted data types where necessary
   - Created calculated fields like: churn rate, Total charges, call frequency levels.
- Data Visualization: Developed an interactive dashboard including:
   - KPI cards (Churn rate, Total charges, ARPU, Churn count)
   - Bar charts (Call frequency vs churn, States vs churn)
   - Line chart (Churn threshold identification)
   - Comparative analysis (Charges vs churn)
   - Filters for state, call frequency, and service usage
 
## Key Insights
 - Customers who frequently contact support are much more likely to leave.
 - Overall churn rate is 14.55% which indicates a significant customer loss risk.
 - Churn increases gradually, then spikes sharply: Once customers reach a certain level of dissatisfaction, churn becomes almost certain.
 - Customers with higher total charges show slightly higher churn
 - Some states have significantly higher churn rates than others which indicates differences in service quality, competition, or infrastructure.

## Recommendations
 - Improve customer service experience by reducing resolution time for complaints, Implement escalation after repeated customer calls.
 - Focus on high-churn regions.
 - Retain high-value customers.

## Conclusion
This project highlights that customer experience especially interactions with customer support is the strongest driver of churn.
